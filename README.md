# Live Translator for Mac

Downloads and update feed for **Live Translator**, the menu bar app that sends a sound booth's feed to [translate.gracecov.app](https://translate.gracecov.app) for live translation.

**Download:** https://translate.gracecov.app/mac (always the latest version). Open the zip and drag **Live Translator** into Applications. Installed copies update themselves.

Requires macOS 14 Sonoma or newer. The application source is maintained separately.
